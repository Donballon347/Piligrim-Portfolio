============================================================
 ПАПКА ДЛЯ ВАШИХ ФОТО И ВИДЕО (постов, Reels, каруселей)
============================================================

Кладите сюда свои файлы, а в index.html заменяйте заглушки.

ПРИМЕР — вставить ФОТО (карусель, пост):
  <img src="media/skolko-vody.jpg" alt="Сколько воды нужно" class="case-media">

ПРИМЕР — вставить ВИДЕО (Reels, Shorts, сторис):
  <!-- с кнопками управления -->
  <video src="media/zvuk-svezhesti.mp4" class="case-media" controls muted loop playsinline></video>

  <!-- автоплей зацикленный, как живой Reels -->
  <video src="media/utrenniy-ritual.mp4" class="case-media" autoplay muted loop playsinline></video>

РЕКОМЕНДАЦИИ:
  • Форматы фото: .jpg / .png / .webp
  • Форматы видео: .mp4 / .webm
  • Идеальный размер: вертикаль 9:16 (1080x1920) или квадрат 1:1 (1080x1080)
  • Вес видео до ~10 МБ на файл — иначе сайт грузится медленно
  • Называйте файлы латиницей без пробелов: utrenniy-ritual.mp4 (не "Утренний ритуал.mp4")
